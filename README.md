# PR3 - Práctica de Redes Neuronales

## Descripción

Práctica académica de introducción a las redes neuronales utilizando Python y la biblioteca Scikit-learn. Se desarrollan diferentes ejercicios de clasificación y evaluación de modelos de aprendizaje automático.

## Objetivos

- Comprender el funcionamiento básico de una red neuronal artificial.
- Entrenar modelos para resolver problemas de clasificación.
- Realizar predicciones a partir de datos nuevos.
- Evaluar el rendimiento de los modelos mediante métricas.
- Interpretar resultados y reconocer las limitaciones de los modelos.

## Tecnologías utilizadas

- **Python**
- **Google Colab**
- **Scikit-learn**
- **Matplotlib**

## Ejercicios realizados

### 1. Clasificación de necesidad de riego

Modelo de clasificación que utiliza la humedad del suelo y la temperatura para predecir si una planta necesita riego.

### 2. Clasificación de correos electrónicos

Modelo que clasifica correos como spam o legítimos a partir de características como las palabras sospechosas y la cantidad de enlaces.

### 3. Clasificación de flores Iris

Utilización del conjunto de datos Iris para predecir la especie de una flor a partir de cuatro medidas.

### 4. Evaluación del modelo Iris

Separación de los datos en conjuntos de entrenamiento y prueba. Evaluación mediante exactitud (*accuracy*) y matriz de confusión.

### 5. Reconocimiento de dígitos escritos a mano

Entrenamiento de una red neuronal para reconocer dígitos del 0 al 9 a partir de imágenes de 8 × 8 píxeles.

## Resultados

- **Clasificación Iris:** exactitud del 100 % en el conjunto de prueba utilizado.
- **Reconocimiento de dígitos:** exactitud del 97,22 % en el conjunto de prueba.
- **Clasificación de riego y spam:** realización de predicciones sobre ejemplos de prueba.

Los resultados corresponden a las ejecuciones realizadas en esta práctica. El rendimiento puede variar según los datos utilizados y la configuración del modelo.

## Aprendizajes

Esta práctica permitió trabajar con el entrenamiento de redes neuronales, la clasificación supervisada, la realización de predicciones y la evaluación de modelos. También permitió observar la importancia de la cantidad y calidad de los datos para obtener resultados fiables.

## Entorno de trabajo

Los ejercicios se desarrollaron en Google Colab utilizando Python y Scikit-learn.
